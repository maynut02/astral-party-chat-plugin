Astral Party Chat 설치

1. Windows x64 Steam판 Astral Party를 종료합니다.
2. BepInEx IL2CPP가 설치되고 한 번 이상 초기화된 게임 폴더를 준비합니다.
   검증된 빌드 참조 환경: BepInEx 6.0.0-be.788, Unity 2022.3.62f3.
3. 설치 ZIP의 BepInEx 폴더를 게임 실행 파일 AstralParty_INT.exe가 있는
   8vJXnINT 폴더에 합칩니다.
   최종 경로: BepInEx/plugins/AstralPartyChat/AstralParty.Chat.dll
   DLL만 받았다면 해당 폴더를 직접 만들고 DLL을 넣습니다.
   기존 버전이 있다면 먼저 BepInEx/plugins 아래의 모든 AstralParty.Chat.dll을
   해당 검색 경로 밖에 백업합니다. 특히 예전 설치 경로인
   BepInEx/plugins/AstralParty.Chat.dll을 남기면 구형 버전이 로드될 수 있습니다.
   새 DLL은 위 최종 경로에 하나만 남겨야 합니다.
   소스에서 scripts/install.ps1을 실행하면 같은 이름의 기존 DLL들을
   저장소 .work/plugin-backups/<설치 시각>/ 아래에 자동 백업합니다.
4. 게임을 실행한 뒤 BepInEx/LogOutput.log의
   'Loading [Astral Party Chat 버전]' 줄에서 설치한 버전이 로드됐는지 확인합니다.
   방/캐릭터 선택/플레이 화면의 채팅 버튼을 누릅니다.

제거: 게임 종료 후 BepInEx/plugins/AstralPartyChat/AstralParty.Chat.dll을 삭제합니다.

서버와 데이터
플러그인은 https://astral.maynutlab.com 의 Party Chat 서버를 사용합니다.
게임 방 번호와 Steam 표시 닉네임을 감지하면 서버에 입장하며,
닉네임·방 번호·캐릭터·P1~P4 정보와 작성한 채팅을 서버에 보냅니다.
방 번호를 아는 다른 사용자가 해당 채팅방에 접근할 수 있습니다.
Steam 계정 소유권을 확인하는 인증이나 종단간 암호화는 제공하지 않습니다.
비밀번호나 개인 연락처 등 민감한 정보는 채팅에 입력하지 마세요.

이 ZIP에는 게임 파일, BepInEx 자체, Unity/IL2CPP 참조 DLL이 포함되지 않습니다.
게임 업데이트 후 호환성이 달라질 수 있습니다.
